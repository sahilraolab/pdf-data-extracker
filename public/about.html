About PDF Suite

Who We Are

Our Story

Why We Built This

It started with a simple observation: every Meesho supplier we spoke to was doing the same painful thing every single morning. They would download their shipping label PDF from Meesho — sometimes hundreds of pages long — and then manually scroll through it, looking for specific cities, exchange orders, or high-quantity shipments to handle separately.

Some were using Ctrl+F in PDF readers. Others were printing everything and sorting by hand. A few had figured out workarounds using spreadsheets, but none of these solutions were reliable or fast enough for a busy dispatch day.

We built the first version of PDF Suite in a single weekend to solve this for one supplier. Within a month, five more suppliers were asking for access. That is when we knew this needed to be a proper product.

2023

First Version — Keyword Filter

Built a basic PDF keyword filter to help one Meesho supplier in Surat extract city-specific shipping labels from a 200-page PDF. Ran it from a simple Node.js script.

Early 2024

AWB & SKU Extraction Added

After suppliers asked for order data export, we added automatic AWB number, SKU code, and order number extraction from each PDF page.

Mid 2024

Delivery Partner Detection

Suppliers handling multiple couriers — Delhivery, Ekart, Xpressbees — needed courier-wise PDFs. We built automatic delivery partner detection and split-download.

2025

PDF Suite — Full Product Launch

Launched PDF Suite as a fully hosted product with the packing tracker, admin dashboard, and personal onboarding. Now serving suppliers across Surat, Jaipur, Mumbai, Delhi, and more.
